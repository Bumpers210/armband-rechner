# Installation auf dem Xiaomi 14 Ultra

1. Die Datei `dist/Armband-Rechner-1.0.0.apk` per USB, Google Drive oder einem
   anderen Übertragungsweg auf das Handy kopieren.
2. Die APK in der Dateien-App öffnen.
3. Falls Android nachfragt, für genau diese Dateien-App die Installation aus
   unbekannten Quellen erlauben.
4. **Installieren** wählen und anschließend den Armband-Rechner öffnen.

Beim ersten Start wird die öffentliche Preisliste geladen und lokal
gespeichert. Danach bleibt die Kalkulation auch ohne Internetverbindung
verwendbar.

Für spätere Updates die neue, mit demselben Release-Schlüssel signierte APK
über die vorhandene App installieren. Die App vorher nicht deinstallieren,
weil eine Deinstallation den lokal gespeicherten Preisstand und alle
Einstellungen löscht.
